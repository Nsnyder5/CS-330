# CS 330: Computational Graphics and Visualization

For my CS 330 project, I created a 3D desktop workspace using C++ and OpenGL. The final scene includes a desk lamp, mug, notebook, pencil holder, pencils, and a textured wooden desktop. I used several primitive shapes to construct the objects, applied textures and materials, incorporated multiple light sources, and implemented camera controls that allow the user to navigate the scene and switch between perspective and orthographic views.

## How Do I Approach Designing Software?

This project helped me develop a more structured approach to software design. One of the biggest skills I gained was learning how to take a larger visual idea and break it into smaller, manageable components. Instead of trying to create each object all at once, I identified the primitive shapes that could be combined to represent it and then worked on its transformations, materials, textures, and placement separately.

My design process was iterative. I began with basic geometry and gradually added camera movement, textures, lighting, and additional scene objects throughout the milestones. I frequently tested the scene after making changes so I could identify problems before adding another layer of complexity. This approach is something I can apply to future projects because breaking a large problem into smaller components makes development and troubleshooting much more manageable.

## How Do I Approach Developing Programs?

Working on the 3D scene changed the way I think about developing larger programs. I became more intentional about separating responsibilities into different functions instead of placing everything inside one large rendering function. Functions for rendering individual objects, setting transformations, applying materials and textures, configuring lighting, and processing camera input made the project easier to understand and modify.

Iteration was a major part of the development process. Many parts of the final scene required several adjustments before they looked or behaved correctly. I changed object positions and proportions, corrected camera movement, adjusted texture scaling, experimented with lighting values, and repeatedly rebuilt and tested the application. Each milestone gave me an opportunity to improve the previous version rather than starting over. By the end of the course, my development process had become much more focused on testing one change at a time, preserving working functionality, and keeping the code organized so later changes were easier to make.

## How Can Computer Science Help Me Reach My Goals?

Computational graphics gave me experience with concepts that extend beyond graphics programming. Working with transformations, coordinate systems, vectors, user input, shaders, lighting, textures, and real-time rendering strengthened both my mathematical reasoning and my ability to understand how several software components work together. It also gave me more experience debugging C++ programs and diagnosing problems involving source code, project configuration, external libraries, and runtime dependencies.

These skills will be useful throughout my education because future computer science courses will continue to require problem solving, modular programming, debugging, and working with unfamiliar systems. Professionally, I may not necessarily specialize in graphics development, but the experience of building an interactive application from multiple interconnected systems is directly applicable to software development. This course also gave me a stronger appreciation for the amount of iteration that goes into polished software and reinforced the importance of writing organized, documented code that can be maintained and expanded later.
